# The Curiosity Room 🔎

**A cinematic mystery game about identity, forgotten memories, and a locked room.**

## About the Game

You wake up in a room you don't recognize. The door is locked, your memories are missing, and strange objects seem to hold clues about your past.

In **The Curiosity Room**, you investigate the room, uncover evidence, and follow a mysterious crescent-moon symbol in search of the truth.

The project is being developed as a beginner-friendly browser game using HTML, CSS, and JavaScript.

## Current Features

- **Opening scene:** Begin the investigation from a dedicated introduction screen.
- **Mysterious note:** Discover a message that points toward the stopped clock.
- **Clock investigation:** Find the number 7 beneath a clock frozen at 12:00.
- **Clue notebook:** Keep track of discoveries made during the investigation.
- **Photograph investigation:** Uncover the message “YOUR NAME IS THE KEY.”
- **Combination drawer:** Enter `1207` to reveal an ID card with a scratched-out name.
- **Crescent-moon clue:** Discover a symbol on the ID card that matches the symbol on the locked door.
- **Story dialogue:** See the player's thoughts change when investigating important objects.
- **Dark visual theme:** A navy-and-gold interface designed to create a mysterious atmosphere.

## How to Play

1. Open the game in your browser.
2. Click **Begin Investigation**.
3. Read the note and investigate the clock and photograph.
4. Use the clues to work out the drawer code.
5. Enter `1207` to reveal the ID card.
6. Investigate the locked door and look for connections between the clues.

## Built With

- HTML
- CSS
- JavaScript

No framework is required for the current version.

## Current Development Status

The opening scene, investigation interface, clue interactions, drawer code, crescent-moon clue, and basic dialogue reactions are implemented.

The full door puzzle, deeper player choices, additional story scenes, and final ending are still planned. This is an ongoing project, not a completed mystery game.

## Project Goal

The goal is to develop a simple webpage into a more immersive, story-driven mystery adventure where discoveries connect together and gradually reveal the truth.
